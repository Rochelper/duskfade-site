# Duskfade Guide & Wiki

A fan-made, source-checked guide site for **Duskfade** — the clockpunk 3D action-platformer by **Weird Beluga** (published by Fireshine Games). Out now on Steam, PS5, Xbox Series X|S, and Nintendo Switch 2.

🌐 **Live site:** https://www.duskfade-guide.com

## What's inside
- **Start Here** — a 5-step new-player roadmap (first hour → final boss)
- **Boss Strategies** — phase-by-phase counters for all 5 emotional bosses (Wrath → Sorrow → Fear → Jealousy → Despair)
- **Full Walkthrough** — region structure and chain-breaking order
- **Combat Guide** — time-freeze dodge, projectile deflects, stamina economy, combo strings
- **Collectibles & Achievements** — every hidden item and all 25 Steam achievements
- **Lore & World**, **News & Updates**, **Endings**, **Secrets**, **How Long to Beat**

## Stack
Static HTML + vanilla JS i18n (English / 中文 / 日本語 / Español) + Adsterra monetization. Deployed via GitHub → Vercel.
